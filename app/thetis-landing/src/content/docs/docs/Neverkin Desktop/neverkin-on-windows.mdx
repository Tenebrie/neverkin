Neverkin Desktop for Windows can be downloaded from the [Downloads](https://neverkin.com/download) page.

Direct download link: [neverkin-desktop-win32-x64.zip](https://github.com/Tenebrie/neverkin/releases/latest/download/neverkin-desktop-win32-x64.zip)

Neverkin Desktop doesn't currently have any known issues on Windows and should run out of the box. If that's not true in your experience, your solution may appear on this page if you let us know!
