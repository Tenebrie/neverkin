Neverkin Desktop for Linux can be downloaded from the [Downloads](https://neverkin.com/download) page.

Direct download link: [neverkin-desktop-linux-x64.tar.gz](https://github.com/Tenebrie/neverkin/releases/latest/download/neverkin-desktop-linux-x64.tar.gz)

Neverkin Desktop doesn't currently have any known issues on Linux and should run out of the box. If that's not true in your experience, your solution may appear on this page if you let us know!

## Package managers

Neverkin is currently not available on any package managers' repositories. Send your suggestion to the dev through the usual channels if you'd like to see it added!
