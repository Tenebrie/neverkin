The **Mindmap** is a place for your visualizations. The sky is the limit. It could be a chart of character relationships, a family tree, the physical layout of rooms in a dungeon, or whatever else you want to use it for.

<Image src={appShowcase01} alt="The Mindmap view, showing a chart of character relationships." />

## Working with the Mindmap

While working with the mindmap, you are working with **Nodes**. A node is a container for another entity type, like an actor, and you create a node by dragging something from the outliner into the mindmap workspace.

<Image src={mindmap01} alt="A few basic mindmap nodes example" />

Alternatively, you can right click (or press Space) in the workspace to open a quick select menu. Search for your entity, or create one directly from this view.

<Image src={mindmap02} alt="Mindmap quick select dropdown" />

You may edit the entities by double clicking their node.

<Aside type="tip">
An entity may have multiple nodes. That's useful if you'd like to use the same character in multiple story arc charts or family trees. A node always has exactly one parent entity, or none at all. 
</Aside>

### Node linking

Nodes can be linked together to show their relationship. To link a node, drag a wire from the slot in the top right corner of the node, or simply start dragging a node with the Shift key held down. Dropping the wire onto another node will link the two, or dropping it on empty space will open the quick select menu, allowing you to quickly create a node and link it immediately.

<Image src={mindmap03} alt="Two nodes linked together" />

You can also right-click or long-click the wire to add a label to it, or flip the link direction.

<Aside type="note">
While node links and mentions may look similar, they are not the same concept. You can mention entities and link nodes independently from each other.
</Aside>

### Cable management

By default, two linked nodes will display a single wire taking the shortest path with minor creative freedom for aesthetic reasons. You may customize the path by pinning the wire to a specific spot either by double clicking it, or by dragging a wire with the left click.

<Image src={cableManagement01} alt="Default link path" />
<Image src={cableManagement02} alt="Adjusted link path" />

You may also use this feature to organize messy mindmaps into something more palatable. To create a wire bundle - a zip tie, if you will - select the wires you want to collect, right-click some spot to place the bundle and choose the "Collect links here" option.

<Image src={cableManagement03} alt="Bulk selection context menu with wires selected" />

And so you may go from a weird mess:

<Image src={cableManagement04} alt="Mindmap nodes before cable management" />

To a slightly more manageable mess:

<Image src={cableManagement05} alt="Mindmap nodes after cable management" />

You are able to place as many pins as necessary. The Collect option chooses the nearest wire segment to your chosen position to pin.

<Image src={cableManagement06} alt="Mindmap nodes with multiple pins in their wires" />

To remove a single wire pin or to release a bunch of wires, you can just double click the pin, or right-click and select the "Unbundle" option.

<Aside type="note">
When moving the nodes, pins stay in place by default. To move them, you may either select individual pins together with the nodes you're moving, or add the entire wire to selection. When the wire is selected, all pins are moved as well.
</Aside>

### Deleting nodes

Right click the node and select "Delete node" to remove the node. This does not delete the underlying entity, only this specific node in the mindmap. (The "Delete parent" option right below it, however, does delete the entity itself.) You may also press the **Delete** key (**Backspace** on a Mac) to delete the node.

### Plain nodes

You can also create plain nodes that don't link to any other entity. Use them for prototyping, for jotting down quick ideas, or for explaining in detail why this character hates that particular establishment.

Plain nodes can have a full rich text description, but they don't show up outside the mindmap.
