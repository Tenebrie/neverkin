Hello! We're glad to have you on board!

Neverkin is an open-source collaborative writing and worldbuilding app for storytellers, DMs, writers and novelists.
Developed by [Maija Lintunokka](https://github.com/tenebrie) and provided to you for free as long as I can maintain it.

Source code available at [https://github.com/tenebrie/neverkin](https://github.com/tenebrie/neverkin).

## Getting started

The easiest way to get started is using the hosted version at [neverkin.com](https://neverkin.com/).

If you want to run the application yourself, please refer either to [Neverkin Desktop](./docs/neverkin-desktop) or the [Self-hosting](./docs/self-hosting) section. The former is a simple way to run Neverkin as a desktop app, while the latter is a way to get a full experience on your private instance.

Regardless of your choice, the [Onboarding](./docs/onboarding) section will help you get oriented.

### Technical support

You can reach the developer very reliably through the [Discord server](https://discord.gg/rD3KdXmqDP) or through the [Contact form](https://neverkin.com/contact).

I am happy to help you with any questions, feature requests or issues you may encounter, and I promise to reply to all messages I receive.
